# Práctica del examen de Python (42 Madrid)

Ejercicios de práctica en Python para el examen Rank 03 de 42 Madrid, resueltos por mí.

## Cómo practiqué

- Simulador de examen: [codewar](https://github.com/Univers42/codewar)
- Ejercicios y enunciados: [rank03.42exam.net](https://rank03.42exam.net/)

## Ejercicios

Cada carpeta contiene un fichero con el mismo nombre que el ejercicio.

- `anagram`
- `bracket_validator`
- `cryptic_sorter`
- `echo_validator`
- `hidenp`
- `inter`
- `mirror_matrix`
- `number_base_converter`
- `pattern_tracker`
- `shadow_merge`

- `string_sculptor`

- `whisper_cipher`

## Uso

```bash
python3 <ejercicio>/<ejercicio>.py
```

Cada fichero incluye un bloque `if __name__ == "__main__":` con ejemplos de prueba.
